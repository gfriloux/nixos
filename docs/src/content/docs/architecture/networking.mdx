## Tailscale

`tailscale0` is in `trustedInterfaces` on clochette and skitarii. clochette also
accepts port 22 from the tailnet range explicitly:

```nix
networking.firewall.extraInputRules = ''
  ip saddr 100.64.0.0/10 tcp dport 22 accept
'';
```
